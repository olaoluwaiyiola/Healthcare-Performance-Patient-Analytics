# Healthcare Performance & Patient Analytics Dashboard

## 📊 Project Overview

This project is an interactive healthcare analytics dashboard developed using Microsoft Power BI. It analyzes patient visits, hospital operations, financial performance, and patient experience to provide useful insights from healthcare data.

## 🎯 Project Objectives

The dashboard was designed to:

- Monitor key healthcare performance indicators
- Analyze patient demographics and visits
- Evaluate hospital operational performance
- Analyze revenue, costs, profit, and profit margins
- Monitor patient satisfaction and outcomes
- Compare performance across states, branches, and departments
- Support data-driven decision-making

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Github

## 📑 Dashboard Pages

### 1. Executive Overview
Provides an overall summary of:
- Total Patients
- Total Visits
- Total Revenue
- Total Cost
- Total Profit
- Average Revenue per Patient
- Average Waiting Time
- Average Satisfaction

### 2. Patient Analysis
Analyzes:
- Patient demographics
- Gender
- Age groups
- Diagnoses
- Patient distribution by state
- Patient distribution by branch
- Patient outcomes

### 3. Hospital Operations
Analyzes:
- Waiting time by department
- Visits by department
- Waiting time by branch
- Visits by branch
- Waiting time by state
- Visits by state

### 4. Financial Performance
Analyzes:
- Revenue
- Cost
- Profit
- Profit Margin
- Revenue by department
- Revenue by state
- Profit by department
- Profit by state
- Revenue trends
- Revenue versus target

### 5. Patient Experience
Analyzes:
- Patient satisfaction
- Satisfaction by department
- Satisfaction by state
- Satisfaction by branch
- Patient outcomes
- Waiting time by outcome
